Settings

Accessibility mode

WCAG 2.2 AA

On: text reaches 4.5:1, controls and focus 3:1, and glass is opaque enough for text over any backdrop. Off: Apple's default values. Add #aa to the URL to open in this mode.

Live contrast check

Measured from the live tokens with the WCAG formula. Glass is measured over the worst possible backdrop.

Appearance

Apple recommends following the system setting. Keep an in-app switch only with System as the default.

Accent color

One accent tints primary buttons, links, selection and focus. Themes keep the brand's hue and adjust only its lightness, so the AA mode stays AA. Add #theme=vzb to the URL to open with a theme.
