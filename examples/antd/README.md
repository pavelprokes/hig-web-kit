# Ant Design example

```bash
npm install
npm run example:antd     # bundles examples/antd with esbuild → examples/antd/dist
# open examples/antd/index.html (add #aa, #dark or #aa-dark to the URL)
```

`App.tsx` follows OS light/dark and Increase Contrast live, and the AA switch re-themes antd through `higAntd()`.
