# apple-hig-web skill

`SKILL.md` is a condensed, self-contained version of Apple's Human Interface Guidelines for building web UI. It covers layering, Liquid Glass, tokens, components, patterns, writing, accessibility and the optional WCAG 2.2 AA mode. Designers can read it as a guide, and AI assistants can load it as a skill (Claude Skills, or a system prompt in Cursor, Copilot and similar tools).

- `SKILL.md` is generated from `SKILL.template.md` by `npm run build`, which inserts the current token block. Edit the template.
- `references/` holds the detailed research notes it was distilled from (foundations, components, patterns, Liquid Glass), with exact numbers and sources. They are paraphrased from Apple's documentation for reference only.
